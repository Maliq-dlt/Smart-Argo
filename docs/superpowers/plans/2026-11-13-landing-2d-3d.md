# Landing 2D + 3D Implementation Plan

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** Ganti video dan sekuens frame landing v5 dengan satu perangkat 3D yang dirakit dari kode (Three.js) dan ilustrasi Lottie berwarna Sage untuk bagian Grow.

**Architecture:** Satu renderer WebGL dimiliki modul singleton `deviceStage.ts`. Tiap bagian landing memasang `DeviceSlot`, berisi poster dan label DOM. Kanvas hidup pindah ke slot yang aktif dan berganti keadaan (mode) di sana. Model 3D diporting dari spike yang disetujui ke `deviceModel.ts`, dan Three.js dimuat sebagai chunk dinamis.

**Tech Stack:** React 19, Vite, GSAP ScrollTrigger + Lenis (sudah ada), `three` 0.187.0, `lottie-web` 5.13.0 (build `lottie_light`), node:test, Playwright (Chrome).

**Spec:** `docs/superpowers/specs/2026-11-13-landing-2d-3d-design.md`. Acuan visual: `design-previews/device-3d-spike-2026-11-13/index.html`.

## Global Constraints

- Versi dependency ditulis exact: `three@0.187.0`, `@types/three@0.187.0` (dev), `lottie-web@5.13.0`.
- Hanya satu konteks WebGL di landing.
- Semua warna lewat token CSS. Tidak ada hex di komponen; pengecualian hanya material Three.js yang dibangun di `deviceModel.ts` (badan sage, baja, tanah), sesuai spike.
- Label hanya berisi fakta dari dokumen proyek (tabel label di spec). Angka dibaca dari kode (`solarInput`, konstanta interval baca), tidak ditulis tangan.
- Teks antarmuka berbahasa Indonesia. Teks cerita yang sudah ada tidak diubah.
- Reduced motion: tanpa kanvas hidup, tanpa putar otomatis, tanpa denyut atau gelombang; tampilkan poster keadaan akhir.
- Di layar sentuh, kanvas memakai `touch-action: pan-y`.
- Commit, push, dan deploy **hanya jika pengguna meminta** (CLAUDE.md). Langkah "Commit" di rencana ini dilewati kecuali diminta.
- Pemeriksaan wajib sebelum menyatakan selesai: `npm run lint`, `npm run typecheck`, `npm test`, `npm run build`, `git diff --check`, `node tests/landing-browser.mjs`, `node tests/route-transition-browser.js`, dan tangkapan layar 1440/768/390/320 terang dan gelap.

## Review Focus

2. Lompat jauh (link nav, `scrollTo`) ke bagian lain: kanvas mendarat di slot yang benar dengan mode yang benar, tidak membawa mode lama. Dites di Task 3.

5. Ukuran jendela berubah dari 1440 ke 390: kanvas mengikuti, dan label tetap di dalam slot. Dites di Task 3.
